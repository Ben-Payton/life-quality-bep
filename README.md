# Installation

## uv (reccomended)

`uv tool install git+https://github.com/Ben-Payton/life-quality-bep.git`


# usage

For usage on a personal machine, and ssh key must be generated for the target and the target must have the alias "wendian" in the ssh known hosts file.

## Commands 

`chkq` prints a list to the terminal with a quick overview of who has jobs submitted and running.
